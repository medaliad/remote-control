================================================================
  VE ADMIN REMOTE AGENT - HOW TO USE
================================================================

This folder lets you put a teammate's PC under remote control
through VE Admin. Only the PC being controlled needs the agent
installed. The PC doing the controlling just needs a browser.


================================================================
  1) INSTALL ON THE PC YOU WANT TO BE CONTROLLED
================================================================

This is the PC whose screen the manager will see.

Steps:
  1. Open this folder ("agent").
  2. Double-click  Setup.cmd
  3. If Windows shows a permission box during Node.js install,
     click "Yes". (Only happens the first time.)
  4. A small dialog appears asking for the username.
        - On a fresh PC: type the username, e.g.  dali
        - On a PC already set up: it pre-fills the previous
          username; just click OK to keep it.
  5. Wait until the window says "ALL DONE!" and close it.

The agent is now running and will auto-start every time this
user logs in to Windows. You don't need to do anything else
on this computer.

To verify it is registered, the agent log shows:
    [autopair] registered (user="dali")
The log lives at:
    %LocalAppData%\VEAdminAgent\agent.log


================================================================
  2) START A REMOTE SESSION FROM ANY OTHER COMPUTER
================================================================

You do NOT install anything on the other computer. Any device
with a modern browser works: laptop, desktop, even a phone.

Steps:
  1. Open a browser and go to your VE Admin URL.
  2. Log in.
  3. Find the user or ticket for the PC you want to control.
  4. Click "Open Session".

The user's PC opens the host page automatically and shares the
screen. Your browser shows their desktop in a window. No codes,
no copy-paste, no PowerShell on either side.

If you see "agent-offline" or a "waiting for agent..." spinner:
the user's PC is off, asleep, or has not been set up yet via
step 1 above. Wake it / install the agent and try again.


================================================================
  3) SET UP ANOTHER TEAMMATE'S PC
================================================================

Repeat step 1 once per teammate's PC, using THEIR username:

  - Copy this whole folder to their PC (USB stick, shared
    drive, zipped email attachment - whatever is easy).
  - On their PC, double-click Setup.cmd in the copied folder.
  - In the dialog, type their username (e.g. aisha, ahmed)
    and click OK.

Each PC ends up registered under its own username so the
manager can pick exactly the right one in VE Admin.


================================================================
  4) CHANGE THE USERNAME LATER
================================================================

The simplest way: just double-click Setup.cmd again. The
dialog now shows the existing username; type a different one
and click OK. Done.

Manual way (advanced):
  - Open  %LocalAppData%\VEAdminAgent\config.json  in Notepad.
  - Change the "autopairUser" line to the new name.
  - Save the file.
  - Open PowerShell and run:
        Stop-ScheduledTask  -TaskName VEAdminAgent
        Start-ScheduledTask -TaskName VEAdminAgent


================================================================
  5) STOP / UNINSTALL
================================================================

To stop the agent for now (will auto-start again on next login):
    Open Task Scheduler -> right-click "VEAdminAgent" -> End

To remove it completely:
    Open PowerShell in this folder and run:
        powershell -ExecutionPolicy Bypass -File .\uninstall.ps1


================================================================
  6) TROUBLESHOOTING
================================================================

"Manager click times out with agent-offline"
    The username on the user's PC and the one the manager
    typed do not match. Re-run Setup.cmd on the user's PC and
    confirm the name. Case and surrounding spaces don't matter
    (Dali = dali = " dali "), but "dali" is NOT the same as
    "dali.adweni".

"Antivirus pops up the first time the cursor moves"
    The agent uses PowerShell + user32.dll to move the cursor.
    Whitelist  %LocalAppData%\VEAdminAgent\  and powershell.exe
    started by the VEAdminAgent task.

"Setup.cmd says winget is not available"
    Old Windows version. Click the link it opens, install
    Node.js LTS manually, then double-click Setup.cmd again.

"Where are the logs?"
    %LocalAppData%\VEAdminAgent\agent.log
